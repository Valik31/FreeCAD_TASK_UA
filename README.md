# FreeCAD: завдання та відеоуроки

Сайт з уроками FreeCAD на **GitHub Pages**: https://valik31.github.io/FreeCAD_TASK_UA/

Нічого встановлювати не треба: ви редагуєте `.md`-файли прямо в браузері на GitHub,
а GitHub сам перетворює їх на звичайні HTML-сторінки (кожен урок має власну адресу, тож його знаходить Google).

## Як це працює

1. Ви змінюєте `.md`-файл і натискаєте **Commit changes**.
2. Автоматично запускається збирання (вкладка **Actions**, «Зібрати сайт»). Воно триває близько 30 секунд.
3. Скрипт `build.py` створює з `.md` файли `.html` і зберігає їх у репозиторій.
4. Ще через хвилину оновлюється сайт.

> ⚠️ Файли `.html`, `search.json`, `sitemap.xml` **створюються автоматично**. Не редагуйте їх вручну: при наступному збиранні зміни зітруться. Змінюйте лише `.md`.

## Структура

| Файл / папка | Що це |
|---|---|
| `home.md` | Головна сторінка сайту |
| `_sidebar.md` | Меню зліва (список уроків) |
| `01-block-1x1.md`, `04-minifig-head.md` … | Сторінки уроків |
| `*.jpg`, `*.png` | Картинки |
| `lesson-template.md` | Шаблон для нового уроку |
| `style.css`, `site.js` | Вигляд сайту і кнопки (прогрес, пошук, меню) |
| `build.py`, `.github/workflows/build.yml` | Збирання сайту (не чіпати) |
| `*.html`, `search.json`, `sitemap.xml` | Готові сторінки (створюються автоматично) |
| `.nojekyll` | Порожній службовий файл. Не видаляти! |

Усі файли лежать в одній папці (корені репозиторію).

## Як додати відео до уроку

1. Відкрийте файл уроку, наприклад `04-minifig-head.md`, і натисніть ✏️ (Edit).
2. Візьміть код відео з посилання YouTube: у `https://www.youtube.com/watch?v=abc123XYZ` це `abc123XYZ`
   (у `https://youtu.be/abc123XYZ` теж `abc123XYZ`).
3. Вставте такий блок, замінивши `VIDEO_ID`:
   ```html
   <div class="video">
     <iframe src="https://www.youtube.com/embed/VIDEO_ID" allowfullscreen></iframe>
   </div>
   ```
4. Натисніть **Commit changes**. Через 1–2 хвилини сайт оновиться.

> Видимість відео на YouTube має бути «Відкритий доступ» або «За посиланням». Приватні відео не покажуться.

## Як додати новий урок

1. На головній сторінці репозиторію: **Add file → Create new file**.
2. Назвіть файл, наприклад `05-nazva.md`: **дві цифри, дефіс**, далі латиницею без пробілів. Саме за такою назвою сайт розуміє, що це урок, і додає кнопку «Виконано».
3. Скопіюйте вміст з `lesson-template.md` і заповніть.
4. У файлі `_sidebar.md` додайте рядок:
   ```
     - [5. Назва уроку](05-nazva.md)
   ```
5. Додайте картку на головну (`home.md`), скопіювавши блок `<a>…</a>` і змінивши адресу на `05-nazva.html`. Прогрес «X з Y» рахується саме за картками на головній.
6. Перший рядок уроку (`# Назва`) стає заголовком сторінки в Google, а абзац «**Що навчимося:**» — її описом. Пишіть їх зрозуміло.

## Прогрес учня

Унизу кожного уроку є кнопка **«Позначити як виконане»**. Після натискання з'являється ✓ у меню, на картці уроку і в смужці прогресу на головній.

Усе це зберігається **у браузері учня** (localStorage), без реєстрації та сервера. Тому прогрес прив'язаний до пристрою й браузера: на іншому комп'ютері або після очищення даних браузера він буде порожній. Вчитель цього прогресу не бачить, контроль виконання йде через здані файли `.FCStd`.

## Як додати картинку

**Add file → Upload files** і перетягніть картинку (назва латиницею, без пробілів).
У тексті уроку: `<img class="preview" src="назва.jpg">`

## Налаштування GitHub Pages (вже зроблено)

**Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)`.**

## Якщо сайт не оновився

Відкрийте вкладку **Actions**. Якщо біля «Зібрати сайт» червоний ❌, відкрийте його й подивіться помилку. Перезапустити збирання вручну: **Actions → Зібрати сайт → Run workflow**.

## Перегляд на своєму комп'ютері (необов'язково)

```
pip install markdown-it-py
python build.py
python -m http.server 3000
```
і відкрити `http://localhost:3000`.

## Іконки інструментів

У папці `icons/` лежать офіційні іконки FreeCAD (ліцензія LGPL). Щоб вставити іконку перед назвою інструмента, пишіть так:

```html
<img class="ic" src="icons/pad.svg" alt="">**Видавлювання**
```

Є такі іконки: `body`, `new-sketch`, `leave-sketch`, `rect`, `rect-center`, `circle`, `polyline`, `external`, `construction`, `horizontal`, `h-distance`, `v-distance`, `point-on-object`, `coincident`, `diameter`, `dimension`, `equal`, `symmetric`, `pad`, `pocket`, `fillet`, `thickness`, `mirrored`, `linear-pattern`, `appearance`, `save`.
Іконки `external` і `construction` взято з FreeCAD 1.0, бо в новіших версіях вони змінилися. Інші іконки можна взяти з репозиторію FreeCAD: `src/Mod/PartDesign/Gui/Resources/icons`, `src/Mod/Sketcher/Gui/Resources/icons`.
